## 中文信息

**标题**：用 Claude Code 构建自动化软件工厂

**原标题译文**：使用 Claude Code 构建你自己的 AI 软件工厂

在软件开发的演进过程中，我们见证了从 1968 年传统的标准化工具，到 2010 年代流行的 CI/CD 流水线，再到如今由人工智能驱动的智能体化工厂。本期视频将带你深入探索这一前沿技术的实操路径，详细讲解如何利用 Claude Code 构建一个基于多智能体协作的“软件工厂”系统。这个系统的核心逻辑在于不再让单个 AI 模型承担所有任务，而是通过构建一套复杂的编排机制，让多个子智能体协同工作，从而自动化处理从最初的需求分析、代码生成到后续的多维度审查等完整开发流程。

在这一期视频中，你将获得非常具体的实操知识点：首先是核心的编排者模式。我们将探讨如何利用高能力的模型作为大脑来驱动多个具备特定功能的子智能体按顺序执行任务。这种架构能够确保复杂的逻辑被拆解成可管理的步骤。其次是关于状态跟踪的高效方案，视频中展示了如何利用 Markdown 文件作为元数据存储，这不仅能保证系统在扩展时依然具有良好的结构，而且非常便于人类开发者去阅读和理解当前的进度。第三是模型分层策略的实战应用，我们将探讨如何将核心编排逻辑交给 Claude 3 Opus 等强模型，而将具体的、重复性高的子任务分配给速度快且成本更低的模型如 Claude 3 Sonnet，从而在保证代码质量的同时优化运营成本。

此外，视频还会深入讲解一些高级的工程技巧。例如，如何结合 Git worktrees 和 TMUX 工具，在多个终端区域中同时运行不同的子智能体，从而实现并行开发多个功能点（比如同时处理添加按钮和制作 404 页面）。我们还将探讨如何在自动化流程中加入多维度的审查机制，涵盖安全、用户体验、界面设计以及代码规范等多个维度。最后，视频还会讨论未来的扩展可能性，例如如何接入 GitHub Issues 作为输入源或者集成 Sentry 来获取生产环境的错误信息，并深入探讨在构建此类系统时，如何在 Token 消耗成本与最终产出质量之间找到最佳平衡点。

这期内容非常适合正在寻求突破、希望利用 AI 技术大幅提升开发效率的开发者和软件工程师。如果你对 Agent 工作流感兴趣，或者希望摆脱繁琐的手动重复劳动，这个视频将为你提供极具参考价值的架构思路。为了能够完全吸收本期内容的精华，建议观众具备基础的 Git 操作知识，熟悉 Claude 系列模型的使用逻辑，并且能够熟练进行基本的命令行操作。

通过观看本期视频并跟随其中的实操逻辑，你将能够建立起一套属于自己的、基于智能体协作的自动化工具链。你将不再仅仅是简单地与 AI 对话，而是学会如何构建一个自动化的生产线：从输入一个需求开始，系统会自动进行分析、编写代码、多重审查，并最终完成合并提交。通过掌握这些核心概念和技术手段，你能够显著提升处理复杂任务的效率，在复杂的软件开发周期中建立起更高效的工作流，真正实现从“手动操作”到“自动化工厂”的跨越式转变。
