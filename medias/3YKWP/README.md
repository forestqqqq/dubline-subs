## 中文信息

**标题**：【中配】看完就能构建具备自主决策能力的AI智能体系统

**原标题译文**：Stanford CS230 | 2025秋季 | 第8讲：Agents、Prompts 和 RAG

这期视频将带你深度解析如何通过提示工程、检索增强生成（RAG）、智能体工作流以及多智能体系统等核心工程手段，最大化基础大语言模型（LLM）的性能，从而构建出能够处理复杂任务、具备自主决策能力的AI智能体系统。我们将从基础模型的局限性出发，探讨模型迭代与工程优化两种不同的改进维度，并深入剖析构建高性能智能体的全套技术栈。

通过本视频的学习，你将掌握以下核心知识点：

首先是提示工程的核心技术与设计原则。提示工程是每个AI从业者都应具备的基础技能，视频将详细讲解如何通过增加上下文、角色扮演、反思机制、思维链（CoT）以及少样本提示（Few-shot）来优化模型的输出效果。我们将通过具体的案例对比，展示如何将简单的指令转化为高质量的提示词。

其次是关于知识获取的深度对比。我们将探讨RAG与微调（Fine-tuning）的权衡。你会了解到为什么在处理知识更新和风格对齐时，提示工程或RAG往往比微调更具效率。视频将深入讲解RAG的原理，包括如何通过分块（Chunking）、嵌入（Embedding）到向量数据库以及假设性文档嵌入等技术，来解决大模型的知识空白、上下文限制和幻觉问题，确保生成答案的可溯源性。

接着是智能体（Agent）的架构与设计。我们将定义智能体的核心组件，包括提示词、上下文管理系统（工作记忆与长期记忆）、工具调用（API）以及资源。视频还会详细区分智能体的不同自主程度：从低自主的硬编码步骤，到半自主的硬编码工具，再到完全自主的自主决策、编写代码并调用网络API的模式。此外，我们还会讨论模糊工程系统中的人机协同（Human-in-the-loop）机制，讲解如何让人工介入修复智能体的输出。

在复杂系统的构建上，视频将重点讲解任务分解策略。构建复杂智能体的关键在于将宏观任务拆解为提取信息、查询数据库、核对政策等具体步骤，并为每一步匹配最合适的组件（如LLM、工具、RAG或记忆）。同时，我们将对比多智能体系统（Multi-Agent Systems）的层级式与扁平式架构，分析其在并行处理能力和智能体可复用性方面的优势。

最后，视频将提供一套完整的评估体系。构建系统后，如何衡量其好坏至关重要。我们将学习如何结合端到端指标（用户满意度）、组件级分析（如工具写入失败）、客观指标（数据准确性）以及定性评估（语气、幻觉分析）来全面评估智能体的表现，并介绍如何利用LLM评判器进行量化评估。

本视频非常适合AI工程师、软件开发人员以及希望构建AI应用的创业者观看。如果你正在寻找从基础模型过渡到复杂智能体系统的技术路径，或者希望了解如何通过工程手段提升AI应用的落地效果，这期视频将为你提供极具价值的实战指导。

观看本视频后，你将能够掌握构建自主决策AI智能体的全流程。你不仅能学会如何编写高质量的提示词，还能理解RAG的底层逻辑，掌握任务分解的思维框架，并能够设计出具备记忆能力、工具调用能力以及多智能体协作能力的复杂系统。通过学习视频中的案例研究，如金融机构利用智能体减少信用风险备忘录耗时的实战经验，你将能够具备从零开始规划、设计并评估一套具备自主决策能力的AI智能体系统的能力。
