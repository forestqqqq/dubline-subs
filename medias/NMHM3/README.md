## 中文信息

**标题**：4小时实战：用 React Native 构建全栈购物清单 App

**原标题译文**：React Native 全栈课程 – Clerk, Postgres, NativeWind

在这段长达 4 小时的实战课程中，我们将带你完整走过一个基于 React Native 构建的全栈移动端应用开发流程。本视频不仅仅是简单的功能演示，而是通过从零开始构建一个包含身份验证、数据库交互以及复杂状态管理的“购物清单”应用（项目名称为 crossify），带你深入掌握从前端 UI 设计到后端逻辑处理的完整全链路开发实战。

在这一期课程中，你将系统性地学习到以下核心知识点：
首先是现代化的技术栈整合，我们将演示如何将 Expo、Clerk、Neon、Drizzle 和 Zustand 这些主流工具组合成一个生产级别的应用架构。在样式开发方面，你将学习如何在 React Native 环境中配置并使用 NativeWind，通过 Tailwind CSS 的语法实现高效的跨平台 UI 样式定制。
在核心功能模块上，课程涵盖了极其重要的身份验证逻辑：我们将利用 Clerk 的内置组件简化登录与注册流程，并编写自定义 Hook 来处理包括 Google、GitHub 和 Apple 在内的多种社交登录。随后进入数据层建设，你将学习使用 Drizzle ORM 来定义数据库 Schema，并封装用于查询和变更的函数，配合 Neon Postgres 建立稳健的后端基础。
此外，课程还会深入讲解如何利用 Expo API Routes 在移动端应用中直接编写后端逻辑，从而避免独立部署复杂后端服务的麻烦。在状态管理方面，我们将使用 Zustand 处理跨页面的全局数据流，并结合 TypeScript 确保复杂嵌套数据的类型安全。针对性能优化，视频会对比 map 与 FlatList 的区别，教你如何通过 FlatList 处理长列表以提升渲染性能。最后，我们还会涵盖生产环境必备的配套功能，包括集成 Sentry 进行运行时错误捕获以及构建用户反馈系统。

本视频非常适合以下几类人群观看：
如果你是一名已经掌握了基础 React 知识，并渴望进阶到全栈开发领域的开发者，这期课程将为你提供清晰的实战路径；如果你正处于移动端开发阶段，希望学习如何在 Expo 环境下构建具备工业级标准的生产应用，或者你需要在项目中整合数据库、处理复杂状态管理和身份验证，那么本视频提供的完整流程将极具参考价值。

通过观看并实践本期课程的内容，你将能够独立完成一个功能完整的跨平台移动端应用。从最初的开发环境搭建与样式配置开始，到后续的后端逻辑集成、数据持久化处理以及最终的性能优化与错误监控，你将掌握一套成熟的开发工作流。学成之后，你不仅能熟练运用 React Native 和 Expo 构建出高性能的 App，还能在实际项目中高效应用多种主流工具链，构建出具备真实商业价值的全栈产品。
