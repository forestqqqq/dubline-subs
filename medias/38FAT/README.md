这期视频将带你深入探索 LangChain 框架的完整生态系统，旨在帮助你从零开始构建起从基础到高级的端到端生成式 AI 应用。无论你是想利用付费 API 开发快速原型，还是希望通过开源模型构建私有化部署的系统，本视频提供的技术路线都能为你提供清晰的指引。我们将不仅停留在简单的模型调用上，而是从宏观的生态架构出发，深入剖析 LangChain 的核心组件，并展示如何配合 LangSmith 进行全方位的监控与调试，以及如何通过 LangServe 实现应用的正式部署。

通过本视频的学习，你将掌握以下核心知识点：

首先是 LangChain 的完整生态架构。你将了解到 LangChain 不仅仅是一个库，它包含核心的 Python 和 JS 库，涵盖了 Chains（链）、Agents（智能体）、Retrieval（检索策略）以及丰富的 Community（第三方集成）。同时，你还将学习配套的生产级工具，包括用于构建 REST API 的 LangServe，以及用于调试、评估和监控 LLM 调用过程的 LangSmith。

其次是核心的数据处理技术。视频将详细讲解如何针对 CSV、PDF 等多种常见文件格式进行数据摄入，并学习如何实现向量嵌入（Embeddings），这是构建检索增强生成（RAG）系统的关键步骤。

第三是高级逻辑的控制与表达。我们将重点讲解 LCEL（LangChain Expression Language）。这是一门专门用于处理并行化、回退机制、追踪以及复杂逻辑组合的表达式语言，是编写复杂 AI 应用逻辑的必备技能。

第四是本地模型的实战操作。为了实现零成本调用并保护数据隐私，视频将演示如何利用 Ollama 工具在本地系统运行 Llama 2 等开源模型。我们将通过实际操作，展示如何将本地模型与 Streamlit 界面结合，构建出一个可以运行的聊天机器人应用。

最后是生产环境的配套保障。你将学习如何通过 LangSmith 实时追踪 LLM 的调用过程，分析成本并查看输出结果。此外，视频还会演示如何编写自定义函数进行输出解析，确保大模型的响应能够严格符合你产品的特定格式要求。

本视频非常适合想要学习如何构建生产级 AI 应用的开发者、数据工程师或 AI 爱好者。如果你具备基础的 Python 编程知识，并且对大语言模型（LLM）有初步的认知，那么这期内容将为你提供极具价值的实战指导。

看完本视频后，你将能够独立完成从环境配置、API 密钥获取到开源模型调用的全流程。你将具备构建完整 AI 应用的能力，能够熟练运用 LCEL 编写复杂的逻辑流，掌握数据摄入与向量化处理的核心技术，并能够利用 LangSmith 和 LangServe 构建出具备监控能力和部署能力的成熟产品。通过本视频的实操演示，你将学会如何通过简单的代码启动应用，并在仪表板上清晰地观测到每一个环节的运行状态，真正实现从理论到实践的跨越。

## 原视频简介

LangChain is a framework for developing applications powered by language models. 
This framework consists of several parts.
LangChain Libraries: The Python and JavaScript libraries. Contains interfaces and integrations for a myriad of components, a basic run time for combining these components into chains and agents, and off-the-shelf implementations of chains and agents.
LangChain Templates: A collection of easily deployable reference architectures for a wide variety of tasks.
LangServe: A library for deploying LangChain chains as a REST API.
LangSmith: A developer platform that lets you debug, test, evaluate, and monitor chains built on any LLM framework and seamlessly integrates with LangChain.
