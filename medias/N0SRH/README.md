## 中文信息

**标题**：1小时实战课：用 Claude Code 在 VS Code 中实现全自动开发

**原标题译文**：Claude Code 全课程 – 自主目标、MCP 以及 VS Code 设置

这期视频是一门完整的 Claude Code 实战课程，旨在带你从零开始在 VS Code 环境中配置并掌握 Claude Code 的核心功能。通过本节课的学习，你将能够深入理解权限模式、自动目标、技能系统以及 MCP 协议等关键技术点，从而构建起一套高效的自动化开发流，显著提升软件交付效率。

在实战过程中，你将掌握以下核心知识点：
首先是关于权限模式（Permission Modes）的深度解析，包括仅进行规划的 Plan 模式、需要授权修改的 Accept Edits 模式、自动执行脚本的 Auto 模式以及绕过安全检查的 Bypass Permissions 模式，帮助你在安全性与自动化程度之间找到平衡。
其次是核心功能操作，包括通过 /goal 命令让 AI 进入循环模式并利用内置评估器进行自我修正，以及如何利用 Skills 系统将复杂的开发任务（如前端设计或修复工单）封装成标准作业程序（SOP）。
此外，课程还会详细讲解上下文管理与成本优化策略。你将学会监控 Token 消耗情况，并在达到阈值时使用 /compact 命令压缩对话以维持模型的准确性；同时学习如何通过连接 OpenRouter 使用 DeepSeek 等更具性价比的模型来节省 API 费用。
在高级集成方面，视频会对比 CLI 与 MCP（Model Context Protocol）协议的区别，演示如何利用 MCP 连接外部工具并实现到 Vercel 等平台的自动化部署。
最后，你还将掌握一系列实用的斜杆命令，如用于恢复会话的 /resume、重置对话的 /clear、切换模型的 /model 以及回退到特定检查点的 /rewind，并学会结合 Git 和 GitHub 进行版本控制，确保在 AI 生成代码的过程中具备良好的回滚能力。

本视频非常适合以下人群观看：
如果你是一名希望利用 Claude Code 实现自动化开发流程的开发者，或者对 AI Agent 工作流、MCP 协议感兴趣的软件工程师，这门课程将为你提供极具价值的实操指导。无论你是希望在 VS Code 环境中集成高级 AI 能力的初学者，还是追求更高效协作工具的进阶用户，都能从中获得实用的技术干货。

看完本期视频后，你将能够熟练配置 Claude Code 的工作环境，掌握核心指令与权限控制逻辑，学会构建基于 SOP 的技能系统，并能利用 MCP 协议连接外部工具。最终，你将具备在 VS Code 中构建全自动开发流的能力，从自动化代码编写到自动化部署都能游刃有余，显著提升你的编程生产力。
