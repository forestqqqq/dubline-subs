## 中文信息

**标题**：2 小时实战：从零开始构建具备记忆与工具调用能力的 AI Agent

**原标题译文**：AI Agents 全课程 | 从入门到进阶（完整指南）

本期视频带你深入探索 AI Agent 的核心奥秘，通过两小时的高强度实战教学，带你从零开始构建具备感知、规划、记忆和工具调用能力的自主智能体。课程不仅涵盖了从基础理论到高级架构的全面知识，还提供了从无代码平台到专业编程框架的多条技术路径，旨在帮助你构建出真正具备生产力的 AI 系统。

在这一期视频中，你将掌握以下核心知识点：
1. 深度理解 Agent 与大语言模型（LLM）的区别，掌握包含大脑、记忆、工具和规划在内的核心组件模型。
2. 掌握关键技术原理，包括 RAG 检索增强生成、包含七大要素的提示工程、以及如何通过 API 让智能体连接外部世界。
3. 学习多智能体编排模式（层级式与序列式），并掌握生产环境中的容错机制、状态管理和监控日志等关键工程实践。
4. 通过五个实战项目进行实操：涵盖语音助手、发票自动处理、客户支持系统、研究验证工具以及基于 Python 和 LangGraph 开发的社交媒体内容生成智能体。

本视频非常适合 AI 领域的初学者、希望通过自动化流程提升生产力的职场人士或创业者，同时也适合想要掌握 Python、LangChain 等技术的开发者及准 AI 工程师。看完本期课程后，你将能够清晰分辨 Agent 的核心架构，掌握多种工具链（如 Zapier、n8n、Langflow）的实操技巧，并具备构建生产级智能体系统以及制定相关商业变现策略的能力。
