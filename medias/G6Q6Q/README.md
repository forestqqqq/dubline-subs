**原标题译文**：Agentic AI – 入门完整课程

本期视频带你深入探索 LangChain 与 LangGraph 框架，通过全方位的实战教学，带你从基础理论跨越到实操环节，构建出具备持久化记忆、RAG 支持及人机交互功能的生产级多智能体系统。

在课程中，你将掌握以下核心知识点：
1. Agentic AI 的核心特征、异步编程优化以及利用 Pydantic 进行数据验证；
2. LangGraph 工作流模型，包括顺序、并行、条件及迭代逻辑的构建；
3. 持久化技术以解决状态丢失问题，并实现流式响应与多线程对话；
4. 进阶功能集成，涵盖工具调用、RAG 技术以及人机协作（HITL）环节；
5. 工程化实战，包括使用 LangSmith 进行监控评估，以及在 AWS 和 Render 平台上的部署流程。

本视频非常适合希望从基础 LLM 应用转向构建复杂自动化智能体系统的开发者，或想学习如何利用 LangGraph 构建专业多智能体系统的初学者。

## 原视频简介

Learn how to build production-ready multi-agent systems and automate workflows using LangChain and LangGraph. You'll master everything from core agentic fundamentals and Pydantic validation to advanced sequential, parallel, and conditional LangGraph workflows. Along the way, you'll implement chat memory, RAG, and human-in-the-loop controls, and finish by deploying your applications to AWS and Render through real-world projects like a custom ChatGPT, trip planner, and auto content agent.
