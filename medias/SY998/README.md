## 中文信息

**标题**：【中配】4.5 万播放的 Groq+Llama3 项目，手搓一个能查 PDF 的问答机器人

**原标题译文**：9-使用 Llama3、Langchain 和 Groq API 构建强大的端到端文档问答聊天机器人

这期视频将带你深入了解如何结合 Llama 3 大模型、Groq 推理加速技术以及 Langchain 框架，从零开始构建一个基于 RAG（检索增强生成）技术的端到端文档问答机器人。在当前的 AI 应用开发中，RAG 技术是解决大模型幻觉、让 AI 能够基于特定私有文档提供准确回答的核心方案。本视频将完整演示从多 PDF 文件读取、文本分块、向量化存储到最终实现精准查询的自动化全流程，帮助你掌握构建高性能问答应用的实战技巧。

通过本视频的学习，你将掌握以下核心知识点：首先是文档处理基础，你会学习如何利用 PyPDFDirectoryLoader 批量读取指定目录下的所有 PDF 文件，并掌握如何使用递归字符文本分割器将长文档按照特定的块大小（如 1000）和重叠度（如 200）进行切分，确保模型能够处理合适的文本单元。其次是向量化与存储，视频将演示如何使用 OpenAI Embeddings 模型将非结构化文本转换为高维向量表示，并利用 Streamlit 的 st.session_state 功能在 Web 应用会话中持久化存储这些向量数据。在核心逻辑构建方面，你将学习如何定义检索器接口，并使用 create_retrieval_chain 函数将检索器与文档链串联，构建出完整的自动化查询流程。最后，视频还会重点讲解如何调用 Groq API 来获得远超传统本地部署的推理速度，并配置流式响应机制，让模型在计算的同时实时输出内容，极大提升用户的交互体验。

本视频非常适合以下人群观看：如果你是一名需要快速搭建 RAG 原型项目的开发者或数据工程师，这期视频提供的端到端实战流程将为你节省大量的摸索时间；如果你对 Llama 3、Langchain 以及 Groq API 有基础了解，但不知道如何将这些组件有机结合到实际业务中，本视频的工程实践将为你提供清晰的思路；此外，如果你是希望将公司内部或个人的非结构化文档转化为可交互问答系统的学习者，本视频提供的技术路径将是你的最佳入门指南。

看完本视频后，你将能够独立完成从零到一的文档问答机器人开发。你不仅能学会如何配置 Groq Cloud 控制台并获取 API 密钥，还能掌握如何在 Streamlit 界面中集成标题、输入框和触发按钮等基本组件。通过实操，你将能够处理如美国人口普查局提供的多份 PDF 文件，并准确查询出诸如 2028 年公共医疗保险覆盖率等具体数据。最终，你将具备构建出具备流式响应能力、推理速度极快且能精准基于私有文档回答问题的生产级 RAG 应用的能力。
