## 中文信息

**标题**：【中配】非凸空间避障：用屏障对与 RRT 手搓安全控制

**原标题译文**：对话何冰寒：Barrier-Pairs RRT - CDC 2020

这期视频将深入探讨机器人运动规划领域中一个极具挑战性的核心问题：如何在非凸工作空间中实现安全且符合复杂时间逻辑的机器人控制。传统的二次规划方法在处理非凸约束以及严格的输入约束强制执行时往往面临严重的局限性，导致机器人难以在复杂的物理环境或复杂的任务逻辑中安全运行。为了解决这一难题，本视频详细介绍了一种结合屏障对概念与RRT采样的新型算法——BPRT。该方法的核心思想是通过构建一系列不变集，作为引导机制，确保机器人能够从初始区域平稳移动到目标区域，并在整个运动过程中严格满足复杂的任务约束。

通过观看本期视频，你将掌握以下核心知识点：

首先是关于屏障对的深度理论。视频将详细解释屏障对是由稳定控制器与屏障函数组合而成的核心概念。你会了解到如何通过数学建模，将次级集转化为不变集，并学习如何将这一合成问题转化为线性矩阵不等式问题进行求解。

其次是关于BPRT算法的构建逻辑。视频将带你回顾RRT算法的基本步骤，并展示如何将其扩展为能够处理非凸状态空间的BPRT算法。重点在于，BPRT如何将RRT的顶点替换为屏障对，并利用小于零的epsilon值水平集生成新的平衡点，从而实现更高效的新采样策略。

此外，视频还会涵盖复杂的动力学建模与不确定性处理。你将学习到基于拉格朗日动力学线性化以及范数界限不确定性的子问题构建方法。这包括如何利用二次包含程序方法来计算受限状态空间区域内的机器人范数界限不确定性，以及如何在平衡点附近考虑位置和速度限制后，获得更精确的鲁棒范数界限线性模型。

最后，视频还会涉及高级任务逻辑的实现。我们将介绍如何利用巴赫自动机将时间逻辑规范转换为形式语言，从而有效地指导机器人的路径规划过程。通过这些知识的整合，你可以理解如何让机器人完成诸如循环访问特定目标等复杂任务。

本视频非常适合以下人群观看：首先是从事机器人运动规划与控制的研究人员和工程师，如果你正在寻找处理非凸环境约束的高级算法，本视频将提供极具价值的理论支撑。其次是需要处理复杂时间逻辑规范（例如循环任务或特定顺序的任务）的自动化系统开发者，视频中关于布基自动机的应用将为你提供实用的技术思路。最后，如果你已经具备了拉格朗日动力学基础以及线性矩阵不等式优化知识背景，那么本视频提供的深层数学推导和算法实现细节将帮助你更高效地完成科研或工程项目。

看完这期视频后，你将能够理解非凸约束对机器人安全控制带来的挑战，并掌握BPRT算法的核心原理。你将学会如何利用屏障对构建不变集，并掌握基于拉格朗日动力学线性化构建子问题的具体步骤。通过学习视频中展示的仿真验证过程，你将能够理解双臂机械臂如何在多面体区域及复杂的非凸工作空间中，在避开障碍区的同时，准确地完成从区域A0到A1、A2的循环移动任务。这不仅能提升你对复杂机器人控制问题的理论认知，更能为你提供一套完整的、可用于实际仿真和研究的算法框架。
