## 原视频简介

This is a full course on how modern AI systems actually work, and instead of jumping between disconnected examples, we learn everything by building one imaginary agent from start to finish. It's a refund agent for Cloud X Berry, a made-up online store, and it starts out simple: a customer says their order arrived broken and asks for a refund. By the end of the course that same agent is calling tools, pulling answers from company documents, running on real infrastructure, getting tested and red-teamed, and handling live traffic in production.
