## 中文信息

**标题**：【中配】10分钟，在Claude Code里手搓一个全自动AI Agent

**原标题译文**：在 Claude Code 中构建你的第一个 AI Agent（11 分钟）。

这期视频将带你深入了解如何利用 Claude Code 工具，在完全不需要编写代码或操作终端的情况下，亲手打造一个功能强大的全自动 AI Agent。我们将以构建一个名为 Daybook 的待办事项 Agent 为核心案例，演示如何让 AI 实现自动规划、调用子代理以及跨设备同步运行的复杂逻辑。无论你是想提升工作效率，还是对 AI 的自动化能力感兴趣，这期内容都将为你提供从零到一的实操指南。

通过本视频，你将掌握以下核心知识点：
首先是 AI Agent 与普通 AI 聊天的本质区别。你会了解到 Agent 是以目标为导向的，它不仅是回答问题，更能自主规划步骤、调用各种工具并持续执行，直到最终目标达成。
其次是子代理机制的应用。视频将展示主代理如何将复杂的任务拆解成多个小任务，并分发给不同的子代理并行处理，最后再汇总结果，这种架构是处理复杂工作流的关键。
接着是 CLAUDE.md 文件的妙用。通过这个文件，你可以持久化地存储自己的个人偏好，比如特定的语言风格、字数限制或安全要求，确保 Claude 在不同的项目中都能保持一致的交互逻辑，避免重复沟通。
此外，视频还会重点讲解 Plan 模式与所谓的 30 秒规则。在正式构建前，通过语音或文字与 AI 进行深度沟通，让它生成详细的构建蓝图，这是确保项目成功的关键步骤。
你还将学习到 Auto 模式的操作逻辑，即在计划批准后，让 Claude 自动执行构建任务，并根据预设的安全规则自动批准或拦截相关操作。
视频还会演示 Artifacts 功能，展示生成的 Agent 界面如何保存在云端，从而实现手机与电脑之间的跨设备协同。
最后，我们将探讨人机协作中的 Human in the loop 概念。在处理如发送邮件等敏感操作时，Agent 仅生成草稿供人类审核，确保最终的决策权始终掌握在用户手中。

本视频非常适合那些想要从简单的 AI 对话转向构建自动化 Agent 的用户，以及希望在不写代码的情况下利用 AI 处理复杂工作流的职场人士或个人用户。如果你已经拥有 Claude 的付费订阅，并且想要探索 Claude Code 的进阶功能，那么这期视频将是你的最佳入门教程。

看完这期视频后，你将能够掌握从目标设定到任务规划的全套流程，学会利用 Claude Code 构建出具备自动化能力的 Agent。你将能够实操出像 Daybook 这样具备自动分类堆栈、节省时间统计、委派分数以及自动生成长期计划表等高级功能的工具，并能在实际场景中通过 Agent 处理联系家人、安排预约、制作指南等多样化的任务。
