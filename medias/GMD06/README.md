## 中文信息

**标题**：看完就能学会构建、管理并部署到 AWS 云端的容器应用

**原标题译文**：学习 Docker – 部署容器化应用的完整 DevOps 课程

本期视频带你深入实战 Docker 技术，从零基础开始学习如何构建、管理并最终将容器化应用部署到 AWS 云端。这不仅是一门基础教学，更是一套完整的实操课程，涵盖了从底层架构原理到云端生产环境部署的全流程。

通过本视频的学习，你将掌握以下核心知识点：
1. 深度理解容器与虚拟机的区别，掌握容器在解决环境一致性、轻量化及依赖管理方面的优势；
2. 解析 Docker 引擎架构，并熟练掌握 docker run, build, push 等核心命令；
3. 深入学习 Dockerfile 指令（如 RUN, CMD, EXPOSE, ENV 等）以及镜像层级优化技巧；
4. 掌握 Docker 网络模型（NAT、Bridge 模式）与数据持久化方案（Volumes 与 Bind Mounts）；
5. 学习使用 Docker Compose 进行多容器编排，简化复杂服务的配置。

本视频非常适合零基础初学者、后端或前端开发人员，以及希望掌握 DevOps 工作流的工程师。
