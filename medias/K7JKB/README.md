## 中文信息

**标题**：【中配】4 小时项目实战，用 WebRTC 做浏览器端视频通话

**原标题译文**：WebRTC 全课程及更多内容

这期视频带你通过两个完整的实战项目，系统深入讲解如何利用 WebRTC 技术构建浏览器端的点对点音视频通话应用。我们将从基础概念出发，解析点对点连接的建立流程，并对比原生 API 开发与集成第三方 SDK 的不同方案。

通过本视频，你将掌握以下核心知识点：
1. 掌握 WebRTC 核心对象 RTCPeerConnection，学习如何创建 Offer 和 Answer 以建立无需服务器中转的连接。
2. 了解信令服务的原理，学习如何通过 WebSocket 交换 SDP 描述和 ICE 候选者，并配置 STUN 服务器解决 NAT 穿透问题。
3. 学习如何监听 onTrack 事件来接收并播放远程用户的音视频轨道。
4. 掌握如何集成 Agora SDK，快速实现多人房间、实时聊天和屏幕共享等复杂功能。
5. 学习使用 CSS Grid 和 Flexbox 布局技术实现视频容器的响应式排列，并利用 localStorage 持久化存储用户信息。
6. 掌握用户生命周期管理，包括加入、离开事件的处理以及页面卸载时的资源清理。

本视频非常适合具备 HTML、CSS 和 JavaScript 基础的前端开发者，或者希望构建 Web 端实时音视频应用的全栈工程师。
