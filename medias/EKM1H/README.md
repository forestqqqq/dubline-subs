## 中文信息

**标题**：【中配】12分钟全流程：从零开始手搓你的第一个 Power BI 仪表板

**原标题译文**：Power BI 入门教程

如果你正面临堆积如山的 Excel 表格，却不知道如何高效地展示数据，或者你正计划进入数据分析领域，却被复杂的工具门槛挡在门外，那么这期视频就是为你量身定制的入门指南。本视频将带你从零开始，完整走一遍从安装软件到最终发布报告的全流程，让你在短短 12 分钟内，掌握构建第一个 Power BI 交互式仪表板的核心实操技能。

在本期视频中，我们将深入拆解 Power BI 的核心工作流。首先，我们将从软件安装与主界面概览开始，带你熟悉 Power BI Desktop 这个强大的免费桌面端工具。接着，我们将进入最关键的数据处理环节，带你理解加载与转换数据的本质区别。通过实操，你将学会如何进入 Power Query Editor 进行数据清洗，包括删除冗余列、核实数据类型、修复标题以及标准化不一致的文本（例如将 US 统一替换为 United States）。同时，你还将学会利用已应用的步骤面板来记录和撤销所有的转换操作，确保数据处理过程可追溯且高效。

除了清洗数据，本视频还会涵盖数据建模的核心逻辑。我们将演示如何通过公共字段（如客户 ID）在模型视图中建立表与表之间的关系，理解多对一等逻辑关系对数据分析的重要性。在可视化构建阶段，我们将亲手制作折线图来展示发货量随时间的变化、使用卡片图快速呈现总收入，并配合表格展示客户名称。最重要的是，你将亲眼看到 Power BI 强大的交互功能：当你点击其中一个图表元素时，画布上所有关联的数据都会自动联动筛选更新。最后，我们将演示如何将完成的报告发布到 Power BI Service，并学习如何将其导出为 PDF 或 Excel，甚至将其嵌入到网页中进行多渠道分享。

这期视频非常适合零基础的 Power BI 初学者，或者是那些需要在职场中处理 Excel 数据、渴望将其转化为动态交互式仪表板的职场人士。无论你是完全没有相关经验的新手，还是想要系统了解数据清洗流程（ETL）和基础数据建模概念的用户，这期视频都能为你提供清晰的实操路径。

看完这期视频后，你将能够独立完成从原始 Excel 数据到专业可视化报告的转化。你不仅能掌握 Power Query Editor 的基础清洗技巧，还能建立起正确的数据建模思维，并学会制作具备交互功能的专业仪表板。通过本教程的学习，你将具备从零开始构建、发布并分享数据报告的能力，让你的数据分析工作从繁琐的手动操作转向高效的自动化可视化。
