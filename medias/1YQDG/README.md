## 中文信息

**标题**：【中配】150万行已验证代码背后的秘密：用AI Agent搞定形式化证明

**原标题译文**：CS Colloquium：与 Nikhil Swamy 探讨Agentic Proof Oriented Program

这期视频将带你深入探索一个极具前瞻性的技术领域：如何利用 AI Agent 在证明导向的编程语言中辅助生成代码并构建形式化证明。随着软件可靠性的要求日益提高，传统的测试手段在面对复杂的系统级漏洞时往往力不从心，而形式化验证提供了一种通过数学证明来确保代码逻辑正确的终极方案。本视频将结合 Project Everest 项目的实战经验，详细拆解在 F* 等语言中，研究人员是如何通过 AI 辅助手段，在处理海量已验证代码的同时，解决 AI 生成复杂规格说明时人类难以审核的难题。

通过观看本期视频，你将获得一系列关于形式化验证与人工智能结合的核心知识点。首先，我们将深入了解 F* 语言的核心原理。F* 是一种证明导向的函数式编程语言，它最大的特点在于支持在编写代码的同时编写规格说明，并利用 Z3 等强大的定理证明器自动检查逻辑的正确性。其次，视频将重点介绍规格审计（Specification Auditing）这一关键技术。由于 AI 在生成复杂的规格说明时可能会引入细微的逻辑漏洞，通过为 AI 生成的规格编写小型面向证明的测试，可以有效地发现并揪出这些隐藏的错误。

此外，视频还会分享如何通过抽象化策略来降低人类的审核难度。通过建立共享的、简洁的规格说明（例如排序算法的通用规格），可以将复杂的证明内容简化，使人类开发者能够更高效地把控核心逻辑。在算法复杂度方面，你将学习到如何利用插桩单调递增计数器并结合分离逻辑（Separation Logic），让 AI Agent 能够证明算法的复杂度边界。对于追求极致性能的开发者，视频还会展示证明驱动的优化技术：在保持顶层定理不变的前提下，利用 AI 消除冗余拷贝，或者在不破坏正确性的情况下切换到 AVX-512 向量化加密等高性能指令集。

视频还涵盖了更贴近工业实践的工具应用，例如 PAL（C 语言证明标注语言）。你将了解到如何在现有的 C 代码中添加标注并将其翻译成 Pulse，从而验证像 Linux 内核中 skbuffs 结构这样复杂的系统级代码。最后，我们还会探讨 AI 在规格变更流程、测试与规格的关系，以及 AI 在教学和知识获取中的巨大潜力。

本视频非常适合软件工程研究者、形式化验证工程师、AI Agent 开发人员，以及对系统编程感兴趣的爱好者观看。如果你对如何用数学手段保障软件安全、对 AI 如何参与到严谨的工程实践中感兴趣，这期内容将为你提供极具价值的启发。为了获得最佳的观看体验，建议观众具备基础的编程能力，并对基本的数据结构与算法有一定了解。

看完这期视频后，你将能够理解 AI Agent 在形式化验证领域的实际应用路径，掌握从规格审计到复杂度证明的核心技术思路。你将学会如何利用抽象化策略简化复杂的证明任务，并了解如何在不牺牲正确性的前提下利用 AI 进行性能优化。更重要的是，通过学习 PAL 等工具的应用，你将掌握如何将形式化验证的思维引入到传统的 C 语言系统开发中，从而提升编写高保障软件的能力。无论你是想深入研究学术前沿，还是希望在实际工程中引入更严谨的验证手段，这期视频提供的技术深度和实战经验都将为你提供强有力的支持。
