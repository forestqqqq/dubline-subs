在本期视频中，你将系统性地掌握以下核心知识点：

首先是逻辑门的基础概念。我们将通过真值表回顾输入信号与输出信号之间的逻辑关系，并对比OR门与XOR门在逻辑逻辑上的本质区别。

接下来是本视频的核心物理原理：衰减场（Evanescent Field）。很多初学者可能认为光场被严格限制在光纤内部，但实际上光场会延伸至界面之外，正是这一特性成为了能量转移的关键。我们将结合全内反射原理，解释由于波前形状受折射率影响，波能量如何始终垂直于波前传播，并被束缚在折射率高的介质中。

随后，我们将深入探讨能量耦合机制。通过观察相邻光纤之间的衰减场如何相互渗透，你会理解光能如何在两条光纤之间来回往返转移。视频中还会明确讲解耦合长度的概念，这是决定能量转移效率的核心物理参数。

此外，视频还会手把手教你相位操纵的技巧。通过调节输入信号之间的相位差，例如延迟30度或90度，我们可以精确控制波能分配到不同输出端口的比例。这对于构建整洁的逻辑门电路至关重要。

最后，我们还会客观分析当前技术的局限性，例如为什么仅靠Mach-Zehnder配置无法直接实现AND或NOR等在无输入时有输出的逻辑，以及在这些情况下需要额外的持续相干输入。
