## 中文信息

**标题**：【中配】Azure SQL Hyperscale最高支持192个虚拟核心且无需额外授权

**原标题译文**：从本地到云端到 Fabric：Microsoft SQL 的现状

这期视频将带大家深入了解 Microsoft SQL 如何通过统一引擎架构，将本地环境、Azure 云端以及 Microsoft Fabric 环境紧密连接在一起。无论您是习惯于传统的 SQL Server 环境，还是正在探索云原生架构，本视频都旨在展示如何在保留原有 SQL 技能的基础上，充分利用自动化维护、AI 辅助运维、向量索引以及多种灵活的托管方案来构建现代化的应用架构。我们将从宏观的架构一致性出发，逐步深入到具体的 AI 时代数据库特性，并最终通过实际的生物医学案例和企业迁移案例，展示 Hyperscale 等高性能方案在处理海量数据和复杂 AI 应用时的强大实力。

通过观看本视频，您将获得以下核心知识点：

首先是关于统一引擎架构的深度解析。您将了解到在 SQL Server 2025、Azure SQL 以及 Microsoft Fabric 中，用户可以获得高度一致的 SQL 体验。这意味着您熟悉的工具、SQL 语法以及 SQL Copilot 的支持，在不同平台间都能无缝衔接，极大地降低了跨平台迁移和开发的门槛。

其次是关于自动化维护与 AI 时代特性的技术细节。视频重点介绍了 Azure SQL Database Hyperscale 提供的自动化功能，包括自动创建索引和自动索引压缩技术，这些功能能够显著提升查询性能并减少人工干预。同时，我们还将探讨面向 AI 时代的数据库特性，包括原生 JSON 支持、向量索引（Vector Indexing）、多模态支持（涵盖列式、账本、内存等多种模式）以及 Fabric 镜像功能，这些特性是构建现代 AI 应用的关键基石。

第三是 AI 辅助运维的实战流程。我们将演示如何利用数据库代理（Database Agent）结合 GitHub Copilot，自动化地识别 CPU 性能问题，并精准定位并修复存储过程中出现的索引不匹配问题。这种从手动排查到 AI 辅助修复的转变，是提升运维效率的重要趋势。

第四是 Azure SQL 不同托管方案的深度对比。视频将详细对比 VM、Azure Local、Managed Instance 以及 Hyperscale 等多种托管方案。特别是 Hyperscale 的核心优势，包括其支持弹性池的高密度部署、Serverless 模式（支持自动暂停与恢复），以及最高可扩展至 192 个虚拟核心的强大能力，且最重要的是，这些扩展无需额外支付许可证费用。

第五是关于向量搜索与 AI 应用构建的实操演示。我们将展示如何利用 Hyperscale 的即时读扩展（Read Scale-out）命名副本，实现毫秒级的向量搜索，并演示如何处理从 4000 行到 10 亿行不等的数据量。此外，视频还会演示如何通过 SQL MCP 服务器连接数据库，并利用 Foundry Agent 自动化执行复杂调查并生成汇总结果。

最后，视频还涵盖了清晰的迁移路径。我们将展示如何从 IaaS 演进到 PaaS，通过移除基础设施负担来简化架构，并利用 Azure Arc 获取云端管理价值。通过生物医学证据浏览器和 HR Block 的实际案例，您将看到这些技术如何在真实业务中落地。

本视频非常适合数据库管理员、系统架构师，以及正在寻找 AI 辅助运维工具或向量数据库解决方案的开发者观看。如果您需要了解如何将现有的 SQL 应用平滑迁移到云端或 Fabric 环境，或者您正在权衡不同 Azure SQL 托管方案的优劣，本视频将为您提供决策支持。
