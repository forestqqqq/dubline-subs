**原标题译文**：迈向 AGI 的规模化扩展是否取决于 System 1 允许 System 2 执行什么？

在人工智能飞速发展的今天，我们正处于一个关键的转折点。过去几年中，AI领域的进步很大程度上依赖于暴力破解的策略，即通过堆砌海量数据、增加模型参数规模以及投入巨量算力来换取能力的提升。然而，随着高质量公开数据的逐渐枯竭以及物理算力成本的不断攀升，这种单纯依靠规模扩张的路径正在遭遇瓶颈。本期视频将深入探讨这一现象，带大家了解为什么传统的暴力破解策略正在失效，以及AI技术如何进入所谓的时代二，并揭示未来通往通用人工智能的全新路径。

通过本期视频的学习，你将深入掌握以下核心知识点：首先是关于AI进化的三个阶段，即时代一、时代二和时代三。我们将探讨在超级鹦鹉假说下，AI如何从单纯的容量扩展转向数据与算力的扩展，并最终走向协同设计的扩展。重点在于，当AI进入第三阶段尝试自我进化时，由于训练自身产生的巨大效率瓶颈，传统的模式将不再适用。

其次，视频将详细拆解视频提出的核心新范式：先预测，再付费。这一理念的核心在于构建System 1与System 2的双系统协同架构。System 1扮演着廉价门卫的角色，负责低成本地预测交互的价值；而System 2作为重型执行器，仅在System 1通过评估后才介入执行昂贵的任务。这种架构能够有效解决当前AI扩展中面临的无效交互浪费问题。

此外，你还将学习到具体的动态自适应循环机制。这包括如何通过执行结果反馈来校准System 1的判断阈值参数kappa，以及如何设计审计样本机制。审计样本的作用至关重要，它通过偶尔执行被抑制的交互来双重检查System 1的盲点，防止因误判导致模型能力停滞。同时，视频还会重新定义AI训练的四步协同设计循环，即表征、预测、门控、学习。通过这种机制，我们可以推动帕累托前沿的偏移，在降低成本和延迟的同时，显著提升任务的成功率。

最后，我们将探讨衡量AGI进步的新标准。未来的衡量标准将从单纯的计算总算力，转向关注有信息的计算密度。这意味着我们不再仅仅关注交互的次数或消耗了多少算力，而是关注每一次交互产生的有效信息增量。

看完本期视频后，你将能够深刻理解当前AI扩展面临的交互瓶颈与物理极限，掌握如何利用双重系统架构拦截昂贵且无效的任务，并学会如何利用动态反馈校准系统参数。你将能够从更高维度的视角审视AI的训练流程，理解如何通过优化计算密度而非单纯堆砌算力来推动模型能力的突破。无论你是技术开发者还是行业观察者，这期视频都将帮助你构建起对未来AI架构演进的深度认知。
