## 中文信息

**标题**：1 小时 4 分钟，用 Spring AI 手搓一个能自动建网站的智能体

**原标题译文**：AI Agent 入门 | 构建你的第一个 AI Agent | FDE 全课程 #5

在这段视频中，我们将从第一性原理出发，深入剖析大语言模型（LLM）的核心逻辑，并带你跨越从“对话机器人”到“智能体（Agent）”的技术鸿沟。很多初学者可能会疑惑，为什么 AI 只是在和你聊天，却不能直接去操作电脑、创建文件或者部署一个网站？本期视频将通过硬核的原理拆解，揭示 LLM 仅能生成文本而无法直接执行外部动作的本质局限性，并引入核心技术——工具调用（Function Calling）机制。我们将详细讲解如何通过定义确定性的工具函数，将用户的自然语言意图转化为结构化的 JSON 指令，从而让 AI 获得操作现实世界的能力。

通过本期视频的学习，你将掌握以下核心知识点：首先，你将深刻理解 LLM 与 Agent 的区别，明确 Agent 是一个包含目标、决策、行动和观测的闭环系统；其次，你将学习区分信息型工具与动作型工具，并了解它们在丰富数据获取与改变环境状态中的不同作用；再次，我们将深入探讨 Spring AI 框架提供的强大能力，看它如何自动识别工具定义和参数，从而极大地简化 Agent 的开发流程。此外，为了确保系统的安全性，视频还会专门讲解如何在受限沙箱环境中运行智能体，通过严格限制权限来防止路径遍历和数据泄目等安全风险。我们还将深入探讨完整的工具调用循环：从 LLM 生成指令到工具执行，再到 LLM 观察结果并决定下一步行动的完整链路。为了应对复杂的任务流，你还会学到如何利用系统提示词（System Prompt）定义角色、限制模型在多步骤任务中的逻辑顺序，以及如何在关键环节引入人类在环（Human-in-the-loop）机制来验证 AI 的输出，确保最终结果的准确性。

本视频特别适合以下几类人群观看：如果你是一名希望深入理解 AI Agent 内部运作机制、不满足于仅仅调用 API 而是想掌握底层逻辑的开发者，这期内容将为你提供扎实的理论支撑；如果你正在学习 Spring Boot 或 Spring AI 框架的技术人员，通过这个实战案例，你可以快速掌握如何利用这些工具构建复杂的业务逻辑；如果你是一名需要构建具备自主执行能力的自动化系统的应用程序工程师，本视频提供的“自动建站”实战案例将为你提供极具参考价值的工程实践；最后，如果你是对 LLM 幻觉问题感兴趣、并希望通过引入工具调用来解决这一技术难题的研究者，这期内容也将为你提供清晰的解决方案。

在看完这期视频并跟随实操后，你将能够从理论到实践全面掌握构建智能体的核心技术。你不仅能理解为什么单纯的 Prompt 无法解决所有问题，还能学会如何通过 Spring AI 构建出具备自主决策能力的 Agent 系统。你会学会如何设计安全的沙箱环境来保护系统安全，学会如何处理复杂的工具调用逻辑，并最终能够独立开发出一个能够自动执行一系列复杂步骤、甚至能够自动化完成网站创建与部署任务的智能体程序。从简单的计算器工具和天气查询到复杂的网站构建服务，你将掌握一套通用的方法论，去解决各种需要 AI 参与的自动化流程问题。
