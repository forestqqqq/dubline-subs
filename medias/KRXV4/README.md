## 中文信息

**标题**：2小时实战：用 TanStack Start 从零构建全栈招聘平台

**原标题译文**：使用 TanStack Start 构建全栈招聘板（包含 Auth、Database、SSR 等）

在这段长达两小时的实战教学中，我们将带你深入探索 TanStack Start 框架的核心能力。本视频将带你从零开始构建一个功能完整的全栈招聘平台，涵盖了现代 Web 开发中的核心技术栈：包括身份验证、数据库集成、服务端渲染（SSR）、严格的类型安全以及多层级的路由保护。通过这个实战项目，你将完整经历从基础环境搭建到复杂业务逻辑实现的整个开发全流程。

在这一期视频中，你可以学到以下具体的知识点：
首先是 TanStack Start 框架的核心特性，包括基于 TanStack Router 和 Vite 构建的架构，它能提供极佳的 SSR 支持和服务端函数（createServerFn）的开发体验。
其次是数据库建模与基础设施搭建，我们将使用 Drizzle ORM 对数据模型进行定义，并配合 Neon Postgres 提供 Serverless 环境下的数据库支持，涵盖了从迁移到持久化的完整流程。
在身份验证方面，视频详细演示了如何集成 Auth.js 处理 GitHub OAuth 登录，并包含自定义 Session 数据注入的实战操作。
关于路由系统，我们将基于 TanStack Router 构建文件路由、动态路由以及 404 处理逻辑，并利用 Zod 对 URL 查询参数进行严格的校验与类型推导。
在数据交互层面，你将学习如何使用 createServerFn 在服务端执行数据库查询和表单提交等关键操作，确保敏感逻辑不暴露给客户端，同时通过 SSR Loader 模式在页面渲染前获取数据。
最后是安全加固，我们将实现双重路由保护机制，在服务端预加载阶段拦截未登录用户，并在后端服务端操作中进行二次权限校验，确保数据的安全性。

本视频非常适合以下人群观看：如果你是希望深入学习 TanStack 生态（包括 Start 和 Router）的开发者，或者正在寻找 Next.js 替代方案、更底层全栈框架的 Web 开发人员，这期内容将非常有帮助。同时，如果你需要掌握 Drizzle ORM 的实战用法、Auth.js 的集成逻辑，或者是对 TypeScript 类型安全在全栈开发中的应用感兴趣的工程师，这个案例将为你提供极具价值的参考。

看完本视频后，你将能够熟练运用 TanStack Start 构建具备 SSR 能力的全栈应用，掌握如何通过 Drizzle ORM 进行高效的数据建模，并能独立实现包含 OAuth 登录、动态路由保护以及类型安全的复杂业务功能（如职位列表过滤、表单提交和权限控制）。
