## 中文信息

**标题**：【中配】Webflow 新平台 Source：让代码库成为唯一真相源

**原标题译文**：查看源代码：使用 Source 研究预览版进行构建

这期视频将带大家深入了解 Webflow 推出的全新平台 Source。Source 的核心理念是让代码库成为构建数字体验的唯一真相源，通过将代码库与内容管理系统及营销工具深度连接，旨在帮助现代团队在 Web 端实现更敏捷的构建与高效的协作。视频将从 Source 的平台愿景出发，带你梳理其核心术语以及技术分层架构，帮助你快速建立对新平台的认知。

通过本期视频的学习，你可以掌握以下具体的知识点：
首先是架构层面的理解，包括 Source 如何通过工作空间、项目和会话这三层架构来管理人员、工具以及协作流程。
其次是关于视图功能的深度操作，视频将演示内置的内容、品牌和站点视图的操作流程，并展示如何通过自定义视图来创建专属的界面原语，例如通过组件导航器视图来查看全站组件实例、交互式变体以及渲染代码。
此外，视频还会重点展示智能体的实际应用场景，包括如何基于 Blueprint 设计系统自动组装页面，以及在图标生成、社交图形制作和代码级编辑中的具体操作。
你还将了解到可访问性视图如何扫描全站诊断标题层级错误并按类型分组修复，以及智能体生成的素材如何直接写入项目文件夹。
最后，视频还会涵盖 Source 支持的 Next.js 和 Astro 等前端框架的集成信息，以及关于定价模式、公测时间等常见问题的解答。

本视频非常适合 Webflow 开发者、营销人员，以及任何希望提升团队协作效率的现代数字团队成员观看。如果你已经了解 Webflow 的基础操作，并且对代码库管理、智能体协作以及自定义界面感兴趣，那么这期视频将为你提供极具价值的参考。

看完本视频后，你将能够清晰理解 Source 的核心逻辑，掌握如何利用自定义视图来管理复杂的全站资源，并学会利用智能体辅助完成从页面组装到代码编辑的各类任务。无论你是希望优化现有工作流的设计师，还是追求技术领先的开发者，Source 提供的这些新功能都将帮助你更高效地构建和维护复杂的 Web 项目。
