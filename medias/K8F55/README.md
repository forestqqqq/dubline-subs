## 中文信息

**标题**：【中配】用 Claude 动态生成工作流，解决大模型处理复杂代码库的协调难题

**原标题译文**：更好的 AI Agents 不是更庞大：动态工作流的力量 - Claude Dynamic Workflows

这期视频将带你深入探讨从单智能体向动态工作流的范式转变。当面对复杂的企业级软件工程时，单智能体往往会因为处理海量上下文而产生协调混乱和幻觉。视频的核心逻辑是：与其追求更大的模型，不如通过让 Claude 在运行时动态生成多智能体编排架构，来解决复杂的协调难题。

通过本视频，你将掌握以下核心知识点：
1. 识别单智能体在处理大规模代码库时的核心瓶颈。
2. 理解动态工作流的核心概念，即 AI 如何实时分析代码库并合成自定义的任务依赖图（DAG）。
3. 掌握动态工作节点的四个严格边界：问题范围、工具集、上下文切片和输出契约。
4. 解析五种核心多智能体拓扑结构：Manager-Worker、Planner-Executor-Reviewer、Map-Reduce、Debate-Verification 以及层级组织。
5. 对比动态工作流与 Apache Airflow（静态编排）及 LangGraph（预定义状态图）的技术差异。
6. 学习五个真实软件工程应用案例，包括 React 框架迁移、全仓库安全审计、Java 遗留代码现代化、架构扩展瓶颈分析以及从零构建 RBAC 功能。

本视频非常适合软件架构师、AI 工程师以及开发者观看，尤其是那些希望超越简单的聊天界面，致力于构建生产级智能体平台，或对多智能体系统（MAS）和自动化软件工程感兴趣的从业者。看完本视频后，你将能够理解如何通过组织更小的、专门的智能体节点来解决复杂的协调问题，并掌握构建弹性数字员工组织的战略思路。
