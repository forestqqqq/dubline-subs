## 中文信息

**标题**：6小时全干货：3D打印与增材制造（AM）工业级实战课

**原标题译文**：3D Printing & Additive Manufacturing – 全课程

本期视频带你深入探索3D打印与增材制造（AM）的工业级实战全流程。课程立足于工业4.0背景，系统性地讲解从底层技术原理、材料科学到CAD数据预处理、DFAM设计优化，直至质量控制与后处理工艺的完整生产链条。

通过本视频的学习，你将掌握以下核心知识点：
1. 增材制造核心工艺分类：涵盖SLA、SLM、EBM等多种工业级技术及其特性对比。
2. 完整的生产工作流：包含从CAD建模到STL/3MF格式转换，再到切片生成G-code的完整链条。
3. 材料科学基础：深入了解聚合物、功能性树脂以及铝、钛、镍基等金属合金的应用。
4. DFAM设计优化策略：学习通过零件整合、轻量化（如点阵结构）、拓扑优化和生成式设计来提升产品价值。
5. 质量控制与后处理：识别翘曲、分层等缺陷成因，掌握抛光、喷砂、热处理等关键工艺。
