## 中文信息

**标题**：【中配】AI 已经能解决千年数学难题，但人类真的不再被需要了吗？

**原标题译文**：AI 将如何改变我们未来的科学发现方式？ | 2026年首尔诺贝尔奖对话

当人工智能开始攻克困扰人类千年的数学难题，甚至能够自主筛选出新型催化剂和药物载体时，我们不得不面对一个深刻的命题：如果AI已经能够完成大部分科学发现的任务，人类在科研中的角色究竟还剩下什么？本期视频将带你深入探讨人工智能如何从一个辅助科研的工具，演变为改变科学发现范式、研究速度以及人类协作结构的核心驱动力。我们将共同剖析在“发现”与“理解”逐渐脱钩的背景下，人类作为科研主体在伦理责任、核心价值以及未来技能要求上的变迁。

通过本期视频，你将深入了解以下核心知识点：

首先是科学范式的根本变革。传统科学研究要求重大的科学发现必须伴随深层的逻辑理解，但AI的介入正在打破这一规则。视频将探讨AI如何推动科研进入“无需深层理解即可获得发现”的新现状，并结合OpenAI在纳维-斯托克斯方程问题上的进展以及Claude在雅可比猜想上的表现，带你感受这种范式转变的冲击力。

其次是AI在材料科学中的实战应用。我们将展示AI如何通过筛选海量候选材料，将人类的精力从繁琐的初步筛选中解放出来，集中于高价值的计算和实验验证。视频还会介绍如何利用AI配合电子显微镜等精密设备，实现对原子运动等微观数据的实时分析，从而大幅提高知识获取的效率。此外，我们还会讨论AI如何促进跨领域知识转化，例如将氢气生产的新型催化剂研究成果应用于药物输送载体的开发。

第三是物理AI与自动化实验室的崛起。我们将解析如何将AI的逻辑推理与机器人技术相结合，构建出所谓的“自动驾驶实验室”。在这个闭环系统中，AI负责提出实验流程，机器人执行实验操作，数据反馈给AI进行优化，如此循环往复。同时，视频也会客观分析目前这类自动化系统所面临的技术瓶颈。

最后，我们将重新定义人类在AI时代的角色。当AI承担了大量的发现任务时，人类的角色正在转向成为“开路人”——负责创造基础框架、传授核心技能以及定义宏观的科研方向。视频将强调人类独有的好奇心和对自然奥秘的纯粹“惊叹感”是目前AI尚无法模拟的核心动力。同时，我们也会警惕过度依赖自动化带来的风险，强调人类必须保留与现实世界、实验操作的直接联系，以确保能够正确引导AI的走向。此外，针对AI意识、超人类推理能力带来的伦理责任，以及对下一代科学家技能要求的变迁，视频也将提供深度的思考视角。

本期视频非常适合科研人员、材料科学家、数学家、AI开发者，以及对科技伦理和科学未来感兴趣的广大公众观看。无论你是身处实验室一线，还是对人工智能的社会影响保持高度关注，这期视频都能为你提供独特的视角。你不需要具备复杂的专业背景，只要拥有基础的科学研究概念，以及对AI/机器学习常识的初步了解，就能顺畅地跟随视频逻辑，深入思考人类与AI在科学探索道路上的共生关系。

看完本期视频，你将能够清晰地理解AI如何重塑当前的科研流程，从宏观的范式变迁到微观的实验自动化，全方位掌握AI驱动科研的核心逻辑。更重要的是，你将能够跳出单纯的技术视角，从哲学和伦理的高度重新审视人类在智能时代的核心价值。通过本期视频的学习，你将能够识别出AI在科研中扮演的真实角色，理解人类作为“开路人”的重要性，并学会如何在AI时代保留人类特有的好奇心与实验实践，从而在未来的科研或技术工作中，更从容地应对AI带来的变革，找到人类不可替代的独特坐标。
