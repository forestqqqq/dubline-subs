## 中文信息

**标题**：反洗钱智能体实战：优化记忆比换大模型更有效

**原标题译文**：用于反洗钱的内存感知 Agent Harnesses —— Nacho Martinez, Oracle

本期视频通过 Oracle 公司提供的反洗钱（AML）智能体实战案例，深入探讨在固定大模型的前提下，如何通过优化记忆管理、上下文工程、工具技能架构以及持续学习机制来构建高效的自主智能体系统。

在视频中，你将学到以下核心知识点：
首先是智能体的全层级架构，包括应用层、模型层、基础设施层和数据层，重点解析其中作为关键可控组件的数据层与循环流程；
其次是深入的记忆管理策略，涵盖受限于上下文容量的短期记忆，以及分为情景、程序性、语义三种类型的长期记忆；
随后将讲解两种核心的上下文工程方案：生成式摘要与基于 ID 的压缩存储，旨在优化窗口效率；
此外，视频还会详细拆解技能蒸馏技术，演示如何将历史对话提取为 Markdown 文件进行向量化以提升持续学习能力；
在检索层面，你将了解到预计算语义嵌入对比传统正则式的优势，以及结合关键词与语义搜索的 RRF 混合检索算法；
最后，视频还将讲解指令层级结构、智能体循环中的工具动态组装，以及如何通过限制迭代次数来防止资源耗尽。

本期内容非常适合正在构建自主运行智能体系统的开发者与架构师，或者关注金融风控、反洗钱等垂直领域 AI 应用的从业者。如果你具备基础的大模型知识，并希望在实际项目中优化上下文管理和记忆机制，这期视频将为你提供实用的技术路径。看完本期内容后，你将能够掌握构建定制化框架的方法，学会绕过复杂的通用系统去解决特定问题，从而构建出更高效、更稳定的智能体应用。
