## 中文信息

**标题**：40分钟带你用Trinity构建4个互相协作的AI Agent

**原标题译文**：用 AI Agent 配置整个机构（Agent 原生机构工作坊，第二场）

如果你正处于从单一 AI 提示词工程向复杂的自动化业务流转型的过程中，那么这期视频将为你提供一个极具实操价值的进阶路径。本期内容聚焦于 Trinity 框架，带你深入了解如何构建一个真正具备“智能体原生”逻辑的代理机构。与简单的线性自动化不同，Trinity 旨在帮助用户建立一个拥有明确组织架构、严格权限控制以及跨智能体协同能力的复杂系统。通过这期视频，我们将以 Keymaker Agency 为实战案例，演示如何搭建包含销售、营销、交付和笔记等多个职能部门的智能体集群，让它们不再是孤立的工具，而是能够像真实公司一样协作的数字团队。

在本次教学中，你将掌握以下核心知识点：
首先是 Trinity 的系统架构与核心定位。作为一款基于 Docker 容器的开源编排工具，Trinity 不仅仅是一个简单的连接器，它旨在构建具备“状态”感知能力并能与人类深度协作的智能体集群。视频会详细讲解其如何支持多模型接入、复杂的权限管理以及通过工作区（Workspace）来隔离不同业务逻辑。
其次是独特的组织架构模型。你会学习到如何引入“幕僚长”（Chief of Staff）这一核心角色，作为整个系统的指挥中枢，去协调和编排下属的各个职能智能体。这种结构能够确保复杂的任务在传递过程中不丢失上下文。
第三是实用的技术操作流程。视频将手把手教你如何利用 migrate 命令识别并转换不同类型的 Agent，将其迁移至 Trinity 兼容格式；同时演示如何从 GitHub 仓库直接部署智能体，并通过标签系统进行高效的组织管理。
第四是核心的跨智能体协作机制。通过配置权限，你可以让销售、营销和交付等不同职能的智能体能够互相感知彼此的存在并共享关键信息，从而实现真正意义上的流程自动化。
最后，视频还会涵盖关于开源版与企业版的定位区别、模型路由（Model Routing）的处理、以及 Canvas 协作界面与 BI 工具的区别等深度问答，帮助你更清晰地规划自己的技术路线。

本期内容非常适合以下人群观看：如果你是一名希望构建“智能体原生”机构或自动化复杂工作流的开发者，这期视频将为你提供完整的架构思路；如果你是熟悉 Docker 环境、具备 GitHub 协作经验以及基础大模型概念的工程人员，你将能快速上手 Trinity 的部署与配置逻辑；此外，对于任何对多智能体协同系统（Multi-Agent Systems）感兴趣，想要从简单的对话式 AI 跨越到生产级 Agent 工作流的用户，这期视频都将是极佳的入门指南。

看完本期视频后，你将能够掌握 Trinity 的核心操作流程，学会利用“幕僚长”架构来组织你的智能体团队。你将具备在 Docker 环境下部署并管理多智能体集群的能力，能够熟练使用迁移工具将现有的 Agent 逻辑整合进 Trinity 系统中。最重要的是，你将学会如何打破智能体之间的信息孤岛，通过权限配置让不同职能的代理相互协作，最终构建出一个能够自动化处理销售、营销和交付等复杂业务流程的“智能体机构”。从简单的自动化脚本到具备组织架构支撑的复杂系统，这期视频将带你完成这一关键的技术跨越。
