## 中文信息

**标题**：52 分钟系统教学：像资深工程师用 Claude Code 写代码

**原标题译文**：Claude Code —— 完整课程：从第一个提示词到子代理和技能点

本期视频将带你深度系统地学习 Anthropic 推出的 AI 编程代理工具 Claude Code。这不仅是基础功能的演示，更是一套从底层逻辑到实战技巧的全方位教学，旨在教会你如何像资深工程师一样，通过结构化指令高效地编写、审查和管理代码。

在视频中，你将掌握以下核心知识点：
首先是环境配置与模型选择，涵盖 Sonnet、Opus 等主流模型对比，以及如何通过 Ollama 在本地运行 Qwen2-Coder 等开源模型；
其次是核心上下文控制，学习通过编写 CLAUDE.md 和 spec.md 文件，利用引用机制定义技术栈和架构规范，精准约束 AI 的行为逻辑；
再次是扩展能力建设，讲解如何利用 MCP 协议连接 Figma、Playwright 等外部工具，让 AI 获取实时数据并跨工具协作；
最后是高级工作流应用，包括通过子代理（Sub-agents）独立执行代码审查任务，以及调用 skills.sh 中海量的预定义技能模板来快速复用专业开发者的思维模式。

本视频非常适合希望提升编程效率的开发者、前端工程师及全栈技术人员，同时也适合对 AI 代理工作流和上下文管理感兴趣的技术爱好者。只要你具备基础的 Linux 命令行操作或 VS Code 使用经验，就能通过本教程掌握核心技巧。
