## 中文信息

**标题**：48 小时内用 Claude Projects 构建出 3 个自动化业务流

**原标题译文**：全新的 Claude Projects 改变了一切

在这期视频中，我们将深度拆解 Claude 最新推出的核心功能——Claude Code Projects。这不仅仅是一个简单的对话框升级，它彻底改变了我们与 AI 交互的逻辑。通过引入 Project 这一概念，系统提供了一个类似于文件夹的结构化空间，旨在解决复杂任务中的智能体编排问题。视频将带你深入了解如何通过这种结构化的工作流，实现主智能体管理全局、子线程执行具体任务，并共享记忆与产出物（Artifacts）的核心逻辑。

通过本期课程的学习，你将掌握以下核心知识点：
首先是组织智能体的编排逻辑，你会了解到 Project 如何作为容器来隔离和组织复杂的业务流，实现管理职能与执行职能的有效分离。
其次是深入理解层级结构设计，包括主智能体作为项目经理的角色、派生出的多个子线程（Threads）、共享的上下文记忆以及统一的产物库。
第三是掌握主对话与派生线程的区别：主对话负责持有全局记忆和任务规划，而具体的工具操作（如运行代码、联网搜索、创建表格等）则在派生出的子线程中完成，从而保证核心逻辑不被琐碎操作干扰。
第四是成本控制与透明度，你将学会如何在项目内清晰地追踪每个子线程消耗的 Token 数量以及所使用的具体模型。
第五是前沿功能的实操应用，包括集成在 Project 中的 Design Mode，它能生成类似 Figma 的交互式设计画布，支持通过语音或文字进行标注修改；同时涵盖多种类型的 Artifacts，包括网页、幻灯片、文档及电子表格的生成与分享。
最后，视频还会展示跨平台同步的体验，例如如何在 iOS 应用上利用语音指令远程操作和修改项目内的内容。

本期视频非常适合以下人群观看：如果你是一名希望利用 AI 进行复杂工作流编排的开发者或内容创作者，这套逻辑将极大地提升你的生产力；如果你是 Claude 的深度用户，且希望更高效地管理项目上下文并精准控制 Token 成本，那么这些新功能将是你的刚需；此外，对于对 AI Agent 自动化、多智能体协作以及 Agent Native 相关趋势感兴趣的专业人士来说，这期内容提供了极具价值的实战视角。

看完本期视频后，你将能够真正掌握 Claude Code Projects 的核心逻辑，学会构建结构化的工作流。你不仅能学会如何在 48 小时内快速搭建出如长篇内容创作、多平台分发以及自动化网站管理等具体的业务场景，还能熟练运用 Design Mode 和多样化的 Artifacts 来提升产出质量。通过学习本视频的内容，你将能够从单一的对话模式跨越到复杂的智能体编排模式，在实际工作中构建出更高效、更可控的自动化工作流系统。
